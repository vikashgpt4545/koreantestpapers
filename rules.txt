SECTION 3: CENTRAL DOWNLOAD ROUTING ENGINE ARCHITECTURE (`pages/download-paper.php`)
--------------------------------------------------------------------------------
1. Central Session Map (`includes/db.php`):
   - Define `$TOPIK_DRIVE_MAP` containing all 16 Google Drive folder URLs mapped by session key.
2. Dynamic Link Resolution:
   - `download-paper.php?session=30th` -> Resolves to 30th TOPIK Google Drive folder.
   - `download-paper.php?session=91st` -> Resolves to 91st TOPIK Google Drive folder.
   - If session key is missing, falls back to default cloud archive or generated PDF vault file.
3. User Experience:
   - Candidate clicks "📥 Download PDF" on any page.
   - Routed to `download-paper.php?session=...`.
   - 5-second countdown progress bar runs.
   - Auto-opens the exact Google Drive folder in a new tab upon completion.
