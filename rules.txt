RULE 3: SUBPAGE WORD COUNT & CONTENT DEPTH (2,000+ WORDS PER PAGE)

- Every single page title and main H1 heading MUST feature at least one primary target keyword:
  1. "korean test papers"
  2. "korean exam paper"
- Maintain high keyword density and natural semantic variations across content sections.

RULE 5: STRUCTURAL CONTAINER BOX LAYOUT
- Use clean, modular container box UI styling across all pages.
- Standardized CSS box models for Exam Lists, Live Test Boxes, Question Cards, Download Tables, and FAQ Accordions.

RULE 6: TECHNICAL SEO & ASSETS
- Schema markup (FAQ Page, Article, Course/Exam schema) on every page.
- Clean semantic HTML5 layout (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`).
- Standardized directory structure:
  - `pages/` (for subpages)
  - `css/` (for styling)
  - `js/` (for interactive live tests)

  - `includes/` (for header, footer, navigation modules)
